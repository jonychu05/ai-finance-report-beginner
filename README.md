# 📊 AI 财报分析工具（AI Financial Report Analyzer）

> 上传上市公司年报 PDF，自动提取核心财务指标、计算比率、勾稽自检、任意指标关键词搜索，并调用大模型生成专业分析报告。
>
> **作品介绍**：源于我在恒生聚源实习的真实痛点——单份年报人工处理约 90 分钟，用 AI 自动化后压缩到 30 多分钟。这是一个从"业务痛点 → 技术实现 → 产品化"的完整作品。

## ✨ 功能亮点

- 📄 **自动解析**：上传年报 PDF 自动读取全文（pdfplumber），支持制造业、银行等不同格式，繁体年报自动转简体
- 🔢 **20+ 核心指标**：自动提取营业收入、净利润、总资产、总负债、ROE、经营现金流等指标，自动计算毛利率、净利率等财务比率
- ✅ **勾稽自检**：总资产 ≈ 负债 + 权益、比率合理区间检查，数据不自洽自动告警
- 📋 **覆盖率 + 人工补充**：列出未提取到的指标，支持手动补录后生成报告——「人工兜底」的产品化
- 🔎 **自定义关键词全文搜索**：输入任意指标名（如研发费用、利息收入），返回数值 + 原文 + 行号；找不到自动给出相似表述候选
- 📊 **多年报对比**：多份年报一次上传，公司 × 指标对比表，按指标类型自动选图（柱状/条形/饼图/圆环/散点/直方图/折线）
- 🤖 **AI 资深专家报告**：四段式专业分析（经营表现/盈利能力/偿债与资产结构/风险提示），严格基于数据、禁止臆造
- ⬇️ **导出**：分析报告下载为 Markdown，指标明细 / 对比数据导出 CSV

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
streamlit run app.py

# 3. 浏览器打开
http://localhost:8501
```

> 生成 AI 报告需要 DeepSeek API Key（在页面左侧填写，仅本地使用，不会上传）。

## 🧰 技术栈

Python · Streamlit（网页）· pdfplumber（PDF 解析）· pandas（数据处理）· 正则表达式（指标提取）· opencc（繁转简）· Plotly（可视化）· DeepSeek API（大模型分析）

## 📁 项目结构

```
├── app.py              # Streamlit 主应用（单份分析 + 多年报对比）
├── indicators.py       # 指标提取引擎（通用化：制造业/银行/繁体/单位自适应）
├── requirements.txt    # 依赖清单
└── .streamlit/         # 深色主题配置
```
